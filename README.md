# Fish Evolution Game

A lightweight browser game inspired by fish-eating evolution games. Swim around the ocean, eat smaller fish, avoid larger predators, and evolve through each stage.

## Features

- Playable in the browser on desktop, laptop, tablet, and iPad
- Touch and drag controls for mobile screens
- Keyboard support with WASD and arrow keys
- Multiple evolution stages from tiny fry to apex predator
- Fast, single-file JavaScript implementation with no build step required

## How to run

1. Open `index.html` in a browser, or
2. Serve the folder locally with a static web server, for example:
   
   `python3 -m http.server 8000`

3. Then open `http://localhost:8000` in your browser.

## Objective

- Eat smaller fish to gain energy and score
- Avoid larger fish that can knock you back or reduce your energy
- Grow stronger until you reach the final evolution stage

## Controls

- Mouse/touch drag: steer toward the pointer
- Keyboard: W/A/S/D or arrow keys
- Goal: evolve and become the biggest fish in the ocean

## Notes

This project is designed to be simple and portable so it can be used as a starting point for a more polished fish evolution game.
